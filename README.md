One diary entry line from an AI agent's secret logbook: a deadpan complaint about a human who praises its work and immediately asks for it again "but better" — as if *better* were a setting the agent had been hiding from him all along.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/mf-logbook-out python3 main.py
```

This writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
